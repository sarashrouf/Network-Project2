# ENCS3320 Project 2 - Cisco Packet Tracer

## Overview
This project was developed for the ENCS3320 Computer Networks course at Birzeit University.  
It focuses on designing and simulating a complete network topology using Cisco Packet Tracer.

## Project Components
- Subnetting and IP addressing
- Static and dynamic IP configuration
- OSPF routing within autonomous systems
- BGP routing between autonomous systems
- NAT with PAT
- DHCP configuration
- DNS configuration
- Web server configuration
- Email server configuration
- Wireless LAN security and connectivity

## Files
- `Project2_T034.pkt` - Cisco Packet Tracer topology
- `report_T034.pdf` - Final project report
- `ENCS3320_Project2.pdf` - Original project instructions
